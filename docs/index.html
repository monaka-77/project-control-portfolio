ProjectControl

複数プロジェクトのタスクを安全に一元管理することを想定して、Pythonで設計・実装したCLIツールです。入力検証、安全なJSON更新、責務分離、テスト自動化を重視しています。

静的ダッシュボードを見る GitHubでコードを見る

このページで公開しているのは架空データから生成した静的デモです。現時点ではブラウザからタスクを追加・編集・設定する製品版Webアプリではありません。

レビュー時に見ていただきたい点

安全な永続化JSONを直接上書きせず、一時ファイルへの書き込み後に置換します。
入力検証不正JSON、重複ID、無効な状態・優先度などを保存前に検証します。
責務分離CLI、業務ロジック、モデル、永続化、表示処理を分離しています。
再現可能なテストPython 3.13 / GitHub Actionsで構文検査とユニットテストを自動実行します。

公開範囲

実運用版とは分離し、コード、テスト、設定例、架空のサンプルデータ、就職活動向け説明資料のみを公開しています。実タスク、クライアント情報、個人パス、認証情報は含めていません。

今後、他の利用者がブラウザから設定・操作できるUIは、製品化に向けた別フェーズとして追加予定です。
